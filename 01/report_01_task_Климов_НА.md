**Задание 9. "Гибридный отчет"**

**Условие** 

Создайте ноутбук со структурой: 1. Ячейка (Markdown): заголовок "Расчет чисел Фибоначчи". 2. Ячейка (Code): функция генерации чисел Фибоначчи. 3. Ячейка (Code): запуск функции и вывод результата. 4. Ячейка (Markdown): жирным шрифтом вывод "Расчет завершен успешно".

**Ответ**
```python
def fibonacci(n):
    fib = [0, 1]
    for i in range(2, n):
        fib.append(fib[-1] + fib[-2])
    return fib[:n]
result = fibonacci(10)
print(result)
```
